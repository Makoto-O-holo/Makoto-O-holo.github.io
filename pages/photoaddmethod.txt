写真の追加方法

1. 画像ファイルを  pages/img/  に配置する
2. js/gallery.js の PHOTOS 配列にエントリを追記する

// 例:
{
  src:      "img/%%%%%%%.jpg",
  thumb:    "img/%%%%%%%.jpg",   // サムネイル（同じファイルでも可）
  title:    "%%%%%%%%",
  titleEn:  "%%%%%%%%%%",
  date:     "%%%%%",
  location: "%%%",                // 任意
  camera:   "#######",         // 任意
  tags:     ["#######", "XXXXXXX"] // CATEGORIES のキーを使う
}

3. 保存してブラウザをリロードすれば完了。
